# CodeMind AI 🧠🚀
> **Your AI Software Development Partner**  
> Converts natural language ideas into production-ready full-stack software through an interactive 5-step engineering journey with built-in code analysis, debugging, and post-generation modification.

---

## 🌟 The 5-Step CodeMind AI Workflow

### Step 1 — User Enters Project Requirements
User enters their project idea in natural language (e.g. *Online Food Ordering*, *Cricket League & Match Management*, *E-Commerce Storefront*). AI parses requirements and features.

### Step 2 — AI Asks the User to Choose Technologies
The AI never decides the technology stack without asking the user first. CodeMind AI presents selectable controls for:
- **Frontend**: React, Angular, Vue, HTML/CSS/JavaScript
- **Backend**: Node.js + Express, Python + FastAPI, Java + Spring Boot, Django
- **Database**: MongoDB, MySQL, PostgreSQL, SQLite
- **AI Model**: Google Gemini (Active & Verified), OpenAI, Built-in Engine
- **Application Scope**: Full-stack application / Frontend only / Backend only
- **Feature Flags**: With/without authentication, With/without payment integration

### Step 3 — AI Generates a Project Plan
Before writing code, AI formulates and displays a comprehensive project plan:
- Project overview & user personas
- Features and module breakdown
- Selected technologies
- Complete folder structure preview
- Database entity & schema design
- RESTful API design specifications
- Implementation sprint milestones  
The user reviews the plan and clicks **"Approve & Generate Project"**.

### Step 4 — AI Builds the Project
Live streaming execution across 5 build stages:
1. **Creating folder structure** (`frontend/`, `backend/`, `database/`)
2. **Generating frontend** (Pages, components, styling, navigation)
3. **Generating backend** (APIs, authentication, business logic)
4. **Creating database** (Collections, schemas, relationships)
5. **Testing and fixing errors** (Automated checks, self-healing validation)

### Step 5 — User Chooses Output Format
Choose from 3 download formats:
1. **Complete Project ZIP** (All source code, folders, and config files — Main output)
2. **Project Documentation** (Real PDF or DOCX with architecture, database schemas, and setup instructions)
3. **Both ZIP + Documentation** (All-in-one bundle)

## 💎 Standout Features

| Feature | What It Does |
| :--- | :--- |
| **Requirement Analyzer** | Finds missing or unclear requirements and asks intelligent clarification questions before building. |
| **Technology Advisor** | Explains advantages, disadvantages, and "best for" recommendations for every frontend, backend, and database choice in real time. |
| **AI Project Builder** | Generates complete, functional, multi-file applications tailored to user specifications. |
| **Code Quality Checker** | Audits generated code for package manifests, JWT auth, CORS, error handling, and security leaks with an A+ score report. |
| **AI Debugger** | Automatically scans and self-heals syntax errors, missing configurations, and route inconsistencies. |
| **Project Documentation** | Exports professional PDF and DOCX technical documentation alongside markdown setup guides. |
| **Natural Language Project Modification** | Allows users to say *"Add an admin dashboard and include a sales report"*, automatically updating existing files and refreshing the ZIP download. |
| **ZIP Export** | Instant packaging with zero external build dependencies. |

## 🚀 Running Locally

```bash
# Start both backend and frontend concurrently
npm run dev
```

- **Frontend Application**: [http://localhost:5173](http://localhost:5173)
- **Backend API Engine**: [http://localhost:5000](http://localhost:5000)
- **AI Provider**: Google Gemini (`gemini-flash-lite-latest`) with offline fallback resilience.
